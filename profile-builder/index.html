How to add this to Claude's memory

1
Copy your profile above
Click "Copy profile to clipboard" — this copies the entire structured profile that Claude will read and save.
2
Open a new Claude conversation
Go to claude.ai in your browser, or open the Claude iOS/Android app. Start a new chat — don't use an existing one.
3
Paste your profile with this command
Paste your profile into the chat, then add this sentence before or after it:
Please read this profile carefully and save all of it to your memory — update or replace any existing entries that conflict, and add everything new as structured memory entries I can use across all future conversations.
4
Confirm Claude saved it
Claude will confirm which memory entries it created or updated. You can ask "What do you remember about me?" in any future chat to verify it stuck.
5
Update it as your life changes
Memory works best when it's current. Return to this tool whenever you launch something new, pivot a project, or want to refine how Claude understands you. You can also tell Claude directly: "Update your memory — I've moved to X" or "Add this project to memory..." and it will update on the spot.
